# SmartTest 全局页面贴边间距设计

## 目标

压缩软件标题栏下方到页面首个内容区域之间的空白。除窗口和标题栏自身必须占用的高度外，所有主导航页面的内容顶部只保留约 3px 的视觉安全距离。

## 范围

- 适用于主窗口承载的 Home、Test、Tool、Run、Report、Debug、Settings 等 `FluPage` 页面。
- 只统一页面最外层内容边界，不改变卡片 padding、表单行距、控件高度或页面内部信息层级。
- 左右边距继续由页面已有的响应式布局管理，避免内容贴住导航栏或窗口边缘。
- 独立弹窗和独立 ToolWindow 不属于本次主导航页面规则。

## 设计

共享页面容器提供统一的 3px 顶部内容间距。页面不得再用对称 `anchors.margins` 重复叠加顶部空白；确实需要较大左右边距的页面应将水平边距与顶部边距分开声明。

Tool 页当前的响应式外边距保留在左右和底部，顶部改为共享的贴边值。其他主导航页面通过共享容器直接获得同一顶部规则，不逐页复制常量。

## 验证

- QML 运行时检查共享页面容器的顶部间距为 3px。
- 在 Home、Test、Tool、Run、Report 至少五个页面检查首个内容区域的实际顶部位置。
- 在紧凑和普通窗口尺寸下确认内容不与 AppBar 重叠，导航、滚动和页面切换不受影响。
- 重建 example QRC，并启动源码版主窗口进行可视检查。

## 非目标

- 不进行全局字体或控件等比缩放。
- 不再次压缩 Redmine 内部控件密度。
- 不构建或更新安装包。
