# Jira 标题文字次数规则设计

## 目标

SmartTest Jira 审查的 Summary 复现概率除百分比和分数外，也接受末尾的文字次数描述，避免将“出现一次”等有效写法判为违规。

## 规则边界

- 保留现有百分比和分数格式，例如 `50%`、`1/2`。
- Summary 末尾新增接受“出现/复现 + 中文或阿拉伯数字 + 次”，例如 `出现一次`、`复现2次`、`出现三次`。
- 次数描述允许位于英文或中文分隔符之后，但必须处于 Summary 末尾。
- 普通正文中包含“次”不视为概率；没有明确次数的“偶现”等词不在本次范围。
- Description 的 `Reproducibility rate` 与 Summary 复用同一个文字次数校验，同时继续接受百分比和分数。
- Description 的文字次数后允许补充一组中文或英文括号说明，例如 `出现一次（问题出现后一直不能恢复）`。
- `偶现`、`出现2` 或正文中间偶然出现的次数文字仍不视为合法概率。

## 所有权与清理

- 规则继续由 `support/jira_integration/audit/rules.py` 单一维护。
- 删除根目录独立的 `jira_handler.py`，后续不再同步两套 Jira 审查实现。
- 不新增兼容包装、转发模块或重复规则表。

## 验收

- 新增 Summary 文字次数的通过用例及相近无效格式的失败用例。
- 保持百分比和分数的现有行为，并验证 Summary 与 Description 共用同一个文字次数校验。
- Jira 审查相关测试、编译检查和 `git diff --check` 通过。
