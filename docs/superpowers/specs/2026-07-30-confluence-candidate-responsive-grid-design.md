# Confluence 候选项目响应式网格设计

## 目标

Project Weekly Audit 的候选项目恢复为响应式多列，并让 Project Collection 区域随内容自动调整高度，消除少量项目时的大块空白。

## 布局

- 页面宽度小于 `800px` 时使用 1 列。
- 页面宽度为 `800–1199px` 时使用 2 列。
- 页面宽度不小于 `1200px` 时使用 3 列。
- 每个项目单元包含复选框、独立年份区域和完整项目名。
- 项目名允许换行，单元格高度取同一网格行中项目内容所需的最大高度。
- 不允许横向滚动、文字重叠或项目裁切。

## 动态高度

- Project Collection 候选区域按实际网格行数计算内容高度。
- 最多直接展示 6 行。
- 少于 6 行时区域收缩到实际内容高度。
- 超过 6 行时区域保持 6 行高度，并启用纵向滚动。
- 没有候选项目时不保留空列表高度。

## 边界

- 仅修改 QML 展示与对应 UI 测试。
- 不修改项目发现、筛选、账号缓存、计划、审查或报告逻辑。
- 保持候选项目选择与 Bridge 的现有 ID 契约。

## 验收

- `520px / 1000px / 1500px` 分别显示 `1 / 2 / 3` 列。
- `0 / 1 / 6 / 18 / 40` 个项目时高度符合动态规则。
- 长中英文项目名完整显示，项目矩形不重叠且不超出视口。
- 超过 6 行时只有纵向滚动。
- 勾选、全选和清空行为保持正常。
