# 取消账号与工具权限映射设计

## 目标

移除账号、产品线、岗位、系统角色与工具可见性/可用性之间的映射关系，使所有账号都能查看并使用当前全部工具。

## 边界

- 保留现有 Common、STB、TV、SmartHome、IPTV、Wi-Fi 分组和页面布局。
- 保留登录、账号资料、`config/personnel.json` 以及人员信息的其他业务用途。
- 不合并、移动、新增或删除业务工具。
- 不调整 Jira、Confluence、Redmine、Daily Report 的业务逻辑。

## 实现

- `ToolBridge` 输出固定的完整工具目录，不读取账号、产品线、岗位或系统角色来计算权限。
- 所有现有分组固定可用；现有工具继续归属原分组。
- 删除仅服务于工具权限映射的人员查询、授权判断、账号变化重算和权限日志代码。
- `DailyReportBridge` 删除岗位权限回调和执行时二次授权，仅保留当前登录凭据要求。
- QML 保留现有分组渲染结构；不再依赖账号权限控制工具内容。
